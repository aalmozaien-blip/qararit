# قراريط — «لقد فرّطنا في قراريط كثيرة»

موقع ثابت لمائة حديث صحيح أو حسن فيها أجر صريح، مع ميزة «تحدي الأسرة».

الموقع منشور على GitHub Pages: https://aalmozaien-blip.github.io/qararit/

- `index.html` و`styles.css` و`app.js`: الواجهة.
- `data/hadiths.json`: الأحاديث (يُولَّد آليًا بعد الفحص، فلا يُعدَّل يدويًا).
- `family/`: تحدي الأسرة.
- `i18n/` و`ar/` و`en/` و`fr/` و`id/` و`ur/`: اللغات.
- `analytics.js`: طبقة القياس المجمّع (لا تعمل قبل ضبط رقم الموقع في أداة التحليلات).
- `privacy/`: سياسة الخصوصية بخمس لغات، وزر إيقاف القياس.
- `admin/`: لوحة الأثر والانتشار للإدارة (تحتاج مفتاح أداة التحليلات).
- `docs/analytics/`: توثيق المؤشرات والأحداث والخصوصية والاختبارات.
